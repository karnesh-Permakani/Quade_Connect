1. Executive Summary & Core Vision

QuadeConnect Project Management is a complete, deep-featured project execution hub built specifically for Architectural Millwork fabrication companies. Thinking as an experienced Millwork Project Manager, a project cannot just be a simple to-do list—it must connect Contract Financials, Work Orders, Architectural Sheets, Engineering Shop Drawings, Mockup Packages, Submittals, QC Reviews, Installer Schedules, and Cloud Document Revision Loops in one unified workspace.

Core Synthesis Formula:
ClickUp Productivity Engine (Grid, Kanban, Gantt, Custom Views, Grouping, Filters, Task Dependencies) + Innergy Millwork ERP Domain (Proj No, Contract vs. Work Order Values, Sheets, Shop Drawings, Submittals, Impediments, Page/Slide Count & Revision History) + S3/Box Cloud & Strict RBAC Cost Hiding.

2. Role-Based Access Control (RBAC) & Cost Visibility Rules

In architectural millwork, Admins manage contract values, billing percentages, and hourly pay rates, while Engineers, Drafters, QC Reviewers, and Operations Heads focus strictly on assigned projects, technical drawings, hours budgeted, and production milestones—with zero visibility into dollar costs or contract prices.

3. Line-by-Line End-to-End Process Workflow (Connecting Your Flow Diagram)

Reference Image 2: Master 6-Phase Process Flow Diagram Connected into QuadeConnect PM
PHASE 1: Sales & CRM Intake Pipeline Lead to Project Conversion
Line 1.1 — Lead Captured: Incoming bid invitation from General Contractor (GC), Architect, Referral, or Web form is logged in CRM.
Line 1.2 — CRM Pipeline Progression: Deal moves through New → Qualified → Study Project → Proposal Submitted.
Line 1.3 — Study Project Evaluation: Pre-award technical study to check architectural sheets, custom wood veneers, AWI grade requirements, and specialty hardware lead times.
Line 1.4 — Decision Gate (Lead Won?): When marked WON, the system automatically: (a) Generates a sequential Project No. (e.g., P-26-1137), (b) Creates the Client Portal Account with restricted permissions, (c) Provisions the cloud storage folder tree in AWS S3 / Box, and (d) Fires an intake alert to Operations.
PHASE 2: Operations & Estimating Setup BOQ / BOM, Hours Pay Plan & Team Allocation
Line 2.1 — Ops Notified of New Project Intake: Operations Head opens the newly created Project shell in QuadeConnect.
Line 2.2 — Analyze Files & Estimate (Blocking = BOQ / BOM): Break down architectural plans into Bill of Quantities (casework cabinets, wall panels, reception desks, trim) and Bill of Materials.
Line 2.3 — Hours Pay & Labor Budget Plan: Admin sets role hourly rates (e.g., Engineering $65/hr, CNC/Fab $45/hr, Finishing $48/hr, Install $55/hr) and allocates budgeted hours per phase. System calculates Estimated Grand Total Cost (visible only to Admin).
Line 2.4 — Create Project Folder & Allocate Team: Ops Head assigns specific Engineers, QC Reviewers, and Field Leads to the project. Assigned staff immediately see the project in their Grid/Kanban (with all cost columns hidden).
Line 2.5 — Set Up Work Orders, Tasks & Milestones: Project is subdivided into numbered Work Orders (e.g., P-26-1132-011p, P-26-1132-025p) with target submittal, fabrication, and installation dates.
PHASE 3: Client Workspace & Cloud File Intake (AWS S3 / Box) External Collaboration Portal
Line 3.1 — Dedicated Restricted Client Dashboard: Client logs into their branded portal and sees only their assigned project(s).
Line 3.2 — Client File Upload via S3 / Box: Client uploads contract drawings, architectural bulletins, specifications, and field schedules. Files stream directly to AWS S3 or Box bucket and appear linked inside the project's Files and Sheets tabs.
Line 3.3 — In-Browser PDF Opening & Markup: Both internal staff and clients click any linked file to open it directly inside the QuadeConnect web viewer (powered by S3/Box signed URLs) without downloading—complete with redline annotations, measurements, and comment pins.
Line 3.4 — Live Meetings & Status Tracking: Client can schedule Google Meet calls, chat with the PM, and watch live Kanban/milestone progress.
PHASE 4: Internal Team Execution (Engineering, QC & Field) Inside-Project Execution
Line 4.1 — Engineering (Sheets → Shop Drawings): Engineers review published Architectural Sheets (e.g., G0.02, A1.01) and draft detailed millwork Shop Drawings (e.g., 101.00 Restroom Mockup, 102.49 Bar Counter) linked to specific Work Orders.
Line 4.2 — Automated PDF Processing (Slide/Page Count & Thumbnails): When a multi-page PDF is uploaded to Sheets or Shop Drawings, the backend counts total pages/slides (displayed as Σ9, Σ4, Σ3, Σ2), extracts title block metadata, and generates per-slide thumbnails.
Line 4.3 — QC Review & Non-Conformance Check: Before any drawing reaches the client, QC opens it in the viewer, runs the Millwork QC Checklist (dimensions, joinery, veneer grain, hardware, ADA clearance), and either approves or flags redlines back to Engineering.
Line 4.4 — Field Team Execution: Installers follow the Installer Schedule, log daily check-ins, upload site photos, and report site blockers in the Impediments tab.
PHASE 5: Revision Loop (REVX) & Submittals Approval Version Control & Immutable Archive
Line 5.1 — Publish Log & Submittal Transmittal: PM selects QC-approved Shop Drawings via Publish Log and packages them into a formal Submittal for the Client/Architect.
Line 5.2 — Client Submits Revision Request (REVX): Client/Architect marks up the PDF in-browser and marks status as Revise & Resubmit or Approved as Noted.
Line 5.3 — Engineering Uploads New Version Set: Engineer revises CAD drawing and uploads a new Version Set (e.g., MOCKUP PACKAGE #1 → MOCKUP PACKAGE #2). The system preserves all prior versions in the Revision History panel with exact issue dates and slide counts.
Line 5.4 — QC Validates → Client Approves: QC verifies the fix; Client approves. The approved PDF is locked as an Immutable Archive in S3/Box and the linked Work Order is released to CNC/Shop Fabrication.
PHASE 6: Finance, Progress Billing & Closeout (Admin Only) Contract vs. Cost & AIA Billing
Line 6.1 — Real-Time Cost Tracking: Admin tracks Original Total Contract, Current Contract Value (including change orders), Work Orders Value, and Estimated Grand Total Cost (Labor hours × hourly pay + materials).
Line 6.2 — Progress Billing: Tracks Billed ($) and Billed % per project and across the entire company portfolio.
Line 6.3 — Closeout & Lessons Learned: Final client sign-off, as-built archive locked, retention invoiced, and lessons learned saved.

When a user clicks into any project (e.g., P-26-1132 - [26011R] AUS Project Oasis (Austin)), the top header displays the project identity, budget health status badge (Budget is up to date), and the Millwork Category Tab Bar:

Category Tab Purpose in Architectural Millwork Key Data, Features & Connections
1. Details Central project charter, client/GC contacts, site address, and labor hour budget plan. Project No, Customer, Architect, GC, Start/End Dates, Assigned Team (Engineers, QC, Ops), Labor Hours Budget vs. Actuals, Financial Summary (Admin only).
2. Custom Fields ClickUp-style dynamic fields tailored to architectural millwork specs. AWI Quality Grade (Economy, Custom, Premium), Veneer Cut/Species, Finish System, FSC Certification Required, Fire Rating, Hardware Supplier, Delivery Floor/Phasing.
3. Study Projects Technical engineering research, complex joinery mockups, & pre-production feasibility. Tracks engineering study hours, 3D CAD prototypes, CNC test cuts, material yield calculations, and value-engineering options before releasing formal Shop Drawings.
4. Work Orders (199) Production & installation packages breaking the contract into buildable scopes. WO Number (e.g., P-26-1132-011p, 025p), Scope Name, Room/Area, Linked Shop Drawings, BOM materials, Fabrication Hours, Ship Date, Install Status.
5. Installer Schedule Field installation crew planning, delivery staging, and site readiness calendar. Gantt/Calendar view of site deliveries, crew assignments, daily field check-in logs, floor-by-floor completion %, and punch list items.
6. Sheets (306 / 216) Master architectural, structural, & interior design contract drawings from client. Sheet No (G0.00, G0.02), Sheet Name, Version Set (90 IFP, Bulletin 01), Issue Date, PDF Slide Count (Σ4, Σ3), In-Browser Viewer & Revision History.
7. Shop Drawings (52) Millwork engineering CAD/PDF fabrication drawings created by internal drafters. Drawing No (100.10, 101.00, 102.49), Name (RESTROOM MOCKUP, BAR COUNTER), Version (MOCKUP PACKAGE #1..#5), Linked Work Order, PDF Slide Count (Σ9, Σ2).
8. Files (174 / 50) Cloud document repository backed by AWS S3 / Box. Organized folders for Specs, Contracts, Cut Sheets, Client Uploads, RFIs, Photos. Pre-signed URLs open all PDFs/images directly inside the web app.
9. QC Review Internal quality assurance gate for Shop Drawings and shop fabrication. Pending QC queue, AWI/Millwork verification checklist, PDF redline markup layer, Approve / Reject / Revise status, Reviewer audit trail.
10. Submittals (42) Formal approval packages sent to Architect/GC (Drawings, Product Data, Physical Samples). Submittal No, Spec Section (e.g., 06 41 00 Custom Casework), Linked Shop Drawings, Transmittal PDF generator, Ball-in-Court tracking, Architect sign-off status.
11. Notes (11) & Impediments (7) Communication threads and active blockers delaying engineering, shop, or install. Impediment severity, root cause (e.g., "Missing field dimensions from GC", "Veneer backordered"), assigned owner, days blocked, resolution log.

  • Upload & Process New Sheets: Uploading a PDF to S3/Box automatically parses the document, counts the number of slides/pages inside the PDF (shown in the grid under Sheet Info as Σ4 = 4 slides, Σ3 = 3 slides, Σ1 = 1 slide), and generates high-res page thumbnails.

  • Interactive Slide Carousel in Viewer: The right-hand canvas displays the active PDF slide with left/right slide preview thumbnails (< and >) so users can flip through every page/slide of a multi-page PDF without leaving the page.
