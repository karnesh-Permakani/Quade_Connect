6-Phase End-to-End Architectural Millwork Workflow

Connecting your uploaded process diagram line-by-line directly into the software architecture.

Phase-by-Phase Process Engine

Phase 1: Sales & CRM Intake Pipeline

Lead captured from GC or website bid invite → Moves through CRM stages → Optional pre-bid Study Project evaluated → Lead Won triggers automatic sequential Project Number generation (e.g. P-26-1132), creates Client Portal login, and provisions AWS S3/Box folders.

Phase 2: Operations & Estimating Setup

Estimators build Bill of Quantities (BOQ) & Bill of Materials (BOM) → Admin sets Hours Pay Plan ($/hr rates for Engineering, CNC/Fab, Finishing, Install) → Ops Head allocates project to specific team members → Project broken into numbered Work Orders (e.g. P-26-1132-011p).

Phase 3: Client Workspace & S3 / Box Intake

Client logs into dedicated portal → Uploads architectural PDFs and addenda via pre-signed S3/Box URLs → Documents link automatically into project Sheets and Files tabs → In-browser PDF viewing with zero download requirements.

Phase 4: Team Execution Inside the Project

Engineering studies architectural Sheets → Drafts detailed CAD Shop Drawings tied to Work Orders → Automated worker scans PDFs to count slides/pages (displayed as Σ4, Σ9) and render thumbnails → QC Team runs 10-point AWI inspection checklist before client submittal.

Phase 5: Revision Loop (REVX) & Submittals

PM publishes approved drawings via Publish Log → Client marks up redlines in-browser → Drafters upload revised Version Set (e.g. MOCKUP PACKAGE #1 → #2) → Prior versions preserved in Revision History → Client approves → File locked as Immutable Archive in S3 and released to shop floor.

Phase 6: Finance & Closeout

Admin tracks Original vs Current Contract, Work Orders Value, and Billed % → Progress billing generated → Final client punch-list sign-off → As-builts locked and Lessons Learned saved.

Role-Based Access Control (RBAC) & Cost Masking

Strict access security guaranteeing that non-admin roles never see contract figures, profit margins, or labor pay rates.
